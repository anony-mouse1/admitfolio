# Admitfolio

**The project rules live in `AGENTS.md`. Read that file now, and treat it as if
it were written here.**

This project is worked on from both Claude Code and Codex. Codex reads
`AGENTS.md`, so that is the single source of truth and this file is only a
pointer to it. Keeping a second copy of the rules here is what let them drift
apart before: this file used to claim `next dev` was broken and that a local
build was blocked, both of which had stopped being true.

When a standing rule changes, edit `AGENTS.md`, never this file.

`HANDOVER.md` is the other half of the pair. `AGENTS.md` is what is always true;
`HANDOVER.md` is the state of the work in flight, rewritten whenever the work
moves between tools. Read it too if you are picking up unfinished work.
